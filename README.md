# SkillArc Mobile

Expo SDK 57 / React Native app for the SkillArc release-one student, parent, and faculty experience. Keane owns Expo, Supabase, authentication, and API integration; eight intern groups build native feature UI.

## Start

1. Read [CONTRIBUTING.md](CONTRIBUTING.md), then claim one GitHub issue for your group.
2. Run `npm ci` and `npm start`. Keane provides development builds and synthetic staging access; never use a production account.
3. Before a PR, run `npm run check`. Include the Jira key, issue number, AI-use disclosure, and Android/iOS evidence.
4. Mobile transport types are generated from the pinned contract in `contracts/mobile-v1.openapi.yaml`. Ask Keane for contract changes; do not edit generated code.

The server API and product release plan live in the private SkillArc repository. Intern-facing issue bodies contain all task details needed without Jira access.
